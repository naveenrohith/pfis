# PFIS Restore Drill Evidence Template

This template is compatible with `scripts/postgres_restore_drill.py`. It does
not claim that a restore drill has been performed.

Run the executable drill from a protected environment and retain its generated
`restore-evidence.json`. For promotion-manifest compatibility, either pass it to
`scripts/build_promotion_manifest.py` with `--evidence restore=PATH` or copy the
approved generated artifact to `restore.json` inside `RELEASE_EVIDENCE_DIR`.

## Required owner-supplied placeholders

- Data recovery owner: `<DATA_RECOVERY_OWNER supplied by data-recovery owner>`
- Source database URL secret reference: `<DATABASE_URL_SECRET supplied by data-recovery owner>`
- Disposable restore database URL secret reference:
  `<RESTORE_DATABASE_URL_SECRET supplied by data-recovery owner>`
- Disposable restore database name:
  `<RESTORE_DATABASE_NAME supplied by data-recovery owner>`
- Release evidence directory:
  `<RELEASE_EVIDENCE_DIR supplied by release owner>`
- Production database name:
  `<PRODUCTION_DATABASE_NAME supplied by data-recovery owner>`

## Command template

```powershell
$env:DATABASE_URL = "<DATABASE_URL_SECRET resolved outside git>"
$env:RESTORE_DATABASE_URL = "<RESTORE_DATABASE_URL_SECRET resolved outside git>"
$env:RESTORE_DATABASE_NAME = "<RESTORE_DATABASE_NAME>"
$env:RELEASE_EVIDENCE_DIR = "<RELEASE_EVIDENCE_DIR>"

python scripts/postgres_restore_drill.py `
  --source-url $env:DATABASE_URL `
  --restore-url $env:RESTORE_DATABASE_URL `
  --confirm-restore-database $env:RESTORE_DATABASE_NAME `
  --artifact-dir $env:RELEASE_EVIDENCE_DIR `
  --output "$env:RELEASE_EVIDENCE_DIR\restore-evidence.json"
```

```json
  "completed_at": "<UTC timestamp generated by script>",
  "source_database": "<source database name generated by script>",
  "restore_database": "<restore database name generated by script>",
  "backup_artifact": "<backup artifact path generated by script>",
  "alembic_revision": "<revision generated by script>",
  "row_counts": {

    "raw_emails": "<count generated by script>",

```
